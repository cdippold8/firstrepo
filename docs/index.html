What You'll Need

Nothing fancy — this whole course can be done with a handful of cheap supplies. Pick pencil, ink, or both.

✏️ Pencil sketching

  • An HB or 2B pencil (a 2H–6B set is nice for shading, but not required)
  • Any smooth printer or sketch paper
  • A soft eraser (kneaded erasers are great for lightening tone)
  • Optional: a blending stump or a rolled bit of tissue

🖋️ Ink sketching

  • A fineliner pen (e.g. 0.3–0.5mm) — easiest way to start
  • Optional: a dip pen and bottled ink for a more traditional feel
  • Smooth, reasonably heavy paper so ink doesn't bleed through
  • No eraser needed — ink mistakes become part of learning to commit to a line

How to use this course

Work through the Path tab in order — each lesson builds on the last. Watch both short videos, then spend a few minutes on the practice prompt before moving on. There's no rush; a lesson a day is plenty.
